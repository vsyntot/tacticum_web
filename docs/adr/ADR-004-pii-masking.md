# ADR-004: PII маскируется до записи в лог

**Статус:** ✅ Принято
**Дата:** 2025
**Автор:** Architect

---

## Контекст

REST-эндпоинты принимают персональные данные клиентов:
- имя (`name`, `client_name`)
- email
- телефон

Эти данные логируются через `AddMessage2Log()` для отладки интеграции с AI-сервисом.
Запись PII в логи в открытом виде создаёт риски:
- утечки при компрометации сервера или доступа к логам
- нарушения **152-ФЗ** «О персональных данных»

---

## Решение

Перед любым вызовом `AddMessage2Log()` данные обязательно маскируются:

```php
// Для массивов (payload целиком):
AddMessage2Log(serialize(tacticum_rest_mask_pii($payload)), 'tacticum_form_request');

// Для строк (ответы внешних сервисов, сообщения об ошибках Bitrix):
AddMessage2Log(tacticum_rest_mask_string($errorMessage), 'tacticum_form_error');
```

**Правила маскировки** (реализованы в `rest_helpers.php`):

| Тип | До | После |
|---|---|---|
| Email в массиве (ключ `email`) | `ivan@example.com` | `i**n@example.com` |
| Телефон в массиве (ключ `phone`) | `+79001234567` | `*********67` |
| Email в строке | `error: ivan@ex.com` | `error: ***@ex.com` |
| Телефон в строке | `phone +79001234567` | `phone ***` |

Функции:
- `tacticum_rest_mask_pii(array $payload)` — рекурсивно обходит массив, маскирует `email` и `phone`
- `tacticum_rest_mask_string(string $value)` — маскирует паттерны email и телефонов в строке

---

## Альтернативы

| Вариант | Почему отклонён |
|---|---|
| Не логировать PII вообще | Теряем отладочную информацию при инцидентах с AI-сервисом |
| Шифрование логов | Избыточно для текущего масштаба |
| Структурированное логирование с фильтрацией | Нет готового решения в Bitrix без внешних зависимостей |

---

## Последствия

✅ Соответствие 152-ФЗ о персональных данных
✅ Отладочная информация сохраняется — структура запроса видна без PII
✅ `pr-check.yml` автоматически предупреждает при нарушении правила

⚠️ `mask_pii()` маскирует только ключи с именами `email` и `phone`
→ Если добавляется новое PII-поле с другим именем — нужно расширить функцию
⚠️ Маскировка не абсолютна — не передавать полные объекты без `mask_pii()`
