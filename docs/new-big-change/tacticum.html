Slide 2 · Манифест

Эра AI пришла не как монолит — как семейство

Эра AI не наступила в виде одного гигантского монолита, которым можно купить «всё AI».

Она наступила как семейство специализированных программ, разделяющих общую инфраструктуру: один LLM-шлюз, одни тенансы, одна память, один аудит. И на этой инфраструктуре — свои продукты для разных задач.

В РФ к 2026 году к этой архитектурной правде добавилась регуляторная: только программы из Реестра отечественного ПО допускаются к госзакупкам и КИИ; со статусом «доверенного ПО» — приоритет даже над обычными реестровыми. Импортные платформы выбывают.

Tacticum — это российский ответ:

  • Не вендор-локин на одной модели.
  • Не «AI-обёртка» над OpenAI API.
  • Не enterprise-копилот от Microsoft.

Это программная экосистема на собственном инфраструктурном ядре, с прикладными продуктами для трёх типичных бизнес-задач — разработки ПО, бизнес-ассистентов, клиентских коммуникаций.

Один поставщик. Один контракт. Одно ядро. Четыре программы в Реестре.

Platform

Tacticum Platform

Программная платформа-ядро для построения, развёртывания и эксплуатации систем искусственного интеллекта на основе больших языковых моделей.

Класс по Минцифре04.13 «Системы искусственного интеллекта» (основной), 04.10, 02.13, 02.09
Для когоКрупные организации, строящие или консолидирующие собственный AI-стек; госкорпорации, банки, телеком, интеграторы
Когда подходитЕсть 2+ AI-приложения с дублирующей инфраструктурой; нужен on-prem с двумя доверенными ОС; требуется единый учёт стоимости LLM
Что внутри17 модулей в 6 группах: RUNTIME (Agent Runtime, MCP Runtime, Workflow Spec Engine), AI (LLM Gateway, Prompt Mgmt, Guardrails), DATA (RAG, Memory, Doc Processing), ACCESS (Identity/RBAC, Tenancy, Credential Pool), IO (Connectors, Event Bus, Embedded MCP Servers), OPS (Observability, SDK)
Чем заменяетПрямые SDK провайдеров в каждом приложении; самописная мультитенантность; локальные .mcp.json; разрозненная наблюдаемость; ручной orchestration durable-workflow
Бизнес-эффектВремя вывода нового AI-приложения с 3–4 месяцев на инфраструктуру до 2–4 недель
ПоставкаOn-prem лицензия, SaaS подписка, ПАК
ДоказательствоНа платформе уже работают Tacticum Agents, Dev, Forum как прикладные продукты

Slide 8 · Reg-ready

Что это даёт заказчику в 2026 году

К 2026 году нормативный пейзаж для AI-ПО в РФ устоялся. Ключевые ограничения и преимущества зафиксированы в обновлённых правилах Минцифры (ПП РФ № 1937 от 28.11.2025) и налоговом кодексе.

Норма / эффектЧто это значит
Реестр Минцифры (ПП № 1236)Только программы из Реестра допускаются к госзакупкам по 44-ФЗ и приоритетным закупкам по 223-ФЗ
Статус «доверенного ПО» (ПП № 1937)С 01.03.2026 — абсолютный приоритет в закупках. Не-доверенные предложения приравниваются к иностранным
Правило двух доверенных ОСС 01.06.2027 для прикладного ПО — обязательная совместимость с Astra Linux и РЕД ОС
Освобождение от НДС (пп. 26 п. 2 ст. 149 НК)При реализации прав на реестровое ПО НДС не начисляется
Налог на прибыль 5% (п. 1.15 ст. 284 НК)Для аккредитованных IT-компаний с ≥70% профильных доходов от реестрового ПО

Slide 10 · Старт

С чего начать

Cascade-ask

1️⃣  DISCOVERY-ЗВОНОК (60-90 минут)
    └─ Какой из 4 продуктов адресует ваш сильнейший pain
       Возможные комбинации (если их несколько)
       Контур развёртывания

2️⃣  PILOT (4-6 недель)
    └─ Один продукт в production на ограниченной аудитории
       Реальные метрики, фиксация baseline

3️⃣  PRODUCTION INTEGRATION (1-3 месяца)
    └─ Подключение к корп-системам
       Полная раскатка

4️⃣  ECOSYSTEM CONSOLIDATION (опционально, по результатам)
    └─ Расширение на другие продукты Tacticum
       Если рассматривается несколько — переход на Platform как ядро

5️⃣  STRATEGIC PARTNERSHIP (опционально)
    └─ Equity / co-development / on-prem deployment c co-governance

Что нужно от заказчика для старта

  1. Уточнить целевой сценарий. Какой из четырёх продуктов наиболее остро адресует текущий pain. Если несколько — какой первый.
  2. Назначить владельца со стороны заказчика. CIO / руководитель бизнес-функции / CX-директор — в зависимости от продукта.
  3. Подготовить пилотный стенд. Виртуальная инфраструктура или dedicated hardware для on-prem пилота.
  4. Согласовать модель поставки. SaaS / on-prem / ПАК — на discovery-этапе.
