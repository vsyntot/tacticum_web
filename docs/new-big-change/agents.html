Slide 2 · Контекст

AI-агенты — уже не эксперимент

2026: бизнес-функции хотят AI-ассистентов вчера. IT не успевает.

  • HR-директор хочет бота-онбординг и предчтение резюме — нужен ещё вчера.
  • Юр-департамент задыхается от типовых проверок договоров.
  • Бухгалтерия отвечает на одни и те же вопросы по командировкам месяцами.
  • Клиентский саппорт горит на первой линии — типовые обращения съедают 60–80% времени операторов.
  • Каждый отдел хочет «корп-ChatGPT, который знает наши процессы».

Бенчмарки рынка (2024–2025)

ИсточникМетрика
McKinsey (Generative AI in HR, 2024)До 70% задач рекрутинга на первой линии — кандидат на автоматизацию
Gartner (CX Predicts 2025)К 2026 году 30% взаимодействий контакт-центров будут полностью разрешаться AI-ассистентами без эскалации
World Economic Forum (Future of Jobs, 2025)Routine cognitive work — основная категория, где AI приносит 30–50% time savings

Что мешает: строить такой стек самим — это 3–4 месяца на инфраструктуру до первой продуктивной задачи.

Slide 3 · Проблема

Что ломается у тех, кто строит сам

ПроблемаЧто происходит без платформы
🔴 Фрагментация LLM-вызововКаждый бот общается со своим провайдером. Нет единого учёта стоимости, нет ротации ключей
🔴 Нет тенансовБот HR-департамента и бот юр-департамента работают в одной памяти. Утечки контекста
🔴 Нет каталога инструментовExcel-парсер написан 3 раза в трёх ботах. Каждое подключение к 1С — отдельный проект
🔴 Нет наблюдаемости стоимостиМесячный счёт от LLM-провайдера = $40 тыс. Кто из ботов сколько потратил — никто не знает
🔴 Нет управления промптамиПромпты живут в коде. Поменять формулировку — нужен релиз. Версионирования нет
🔴 Регрессии без guardrailsАгент начинает галлюцинировать через неделю после обновления модели. Никто не замечает до жалобы
🔴 Каналы — каждый раз с нуляПодключение бота к Telegram, веб-чату, MAX — каждый раз новый интеграционный проект

Итог: первый AI-ассистент строится 4 месяца. Второй — 3 месяца. Третий — 3 месяца. Никакого ROI от платформенного эффекта нет, потому что платформы нет.

Slide 4 · Решение

Готовая мультиагентная платформа

Tacticum Agents — это не «конструктор ботов». Это тонкое прикладное приложение поверх Tacticum Platform: оно владеет бизнес-доменом и UI, но описывает агентов как декларативные манифесты — а исполнением, LLM, MCP-инструментами, каналами и наблюдаемостью занимается платформа.

Что меняется: время от «нам нужен бот» до production — с 3–4 месяцев до 4–6 недель. Первая фича закрывается за дни, а не месяцы.

Slide 7 · Reference-кейсы

Benchmark-уровень внедрений

Размещены индустриальные benchmark-цифры. Конкретные кейсы заказчиков добавляются по мере подписания соглашений о публичности.

HR-конвейер

  • Воронка: входящий поток резюме → бот извлекает структуру → ранжирует по критериям → отдаёт shortlist рекрутёру.
  • Эффект: time-to-shortlist −60–70%; точность ранжирования сопоставима с senior-рекрутёром.
  • Стек: граф агента + парсинг PDF/DOCX + MCP-инструмент LinkedIn/HH-выгрузки + RAG по критериям + интеграция с ATS.

Юр-проверка договоров

  • Воронка: входящий договор → бот сравнивает с шаблоном → формирует таблицу отклонений → эскалирует юристу.
  • Эффект: время первой проверки −50–60%; обнаружение отклонений 90–95%.
  • Стек: граф агента + MCP Word + RAG по библиотеке шаблонов + чек-листы отклонений.

Контакт-центр первой линии

  • Воронка: входящее сообщение → бот распознаёт намерение → отвечает по сценарию или эскалирует.
  • Эффект: automation rate 40–60%; снижение нагрузки операторов на 30–50%.
  • Стек: граф агента + RAG по продуктовой документации + CRM через MCP + Telegram + веб-чат + SIP.

Tacticum Agents — приложение на инфраструктуре Tacticum Platform. Один LLM-шлюз и одно тенансное ядро на все продукты заказчика, включая Tacticum Dev и Tacticum Forum.

Один Agent Runtime — три DSL. Тот же движок, который исполняет агентов Agents, исполняет сценарии Tacticum Forum и analysis-subagent'ов Tacticum Dev. Это не три отдельных runtime'а — это один универсальный исполнитель декларативных графов.

Slide 11 · Старт

Cascade-ask + что нужно для пилота

1️⃣  DISCOVERY (60 минут)
    └─ Какие 1-2 сценария дают самый быстрый ROI у вас

2️⃣  PILOT (4-6 недель)
    └─ Один граф агента в production
       С реальной аудиторией, с реальными метриками

3️⃣  INTEGRATION + ROLL-OUT
    └─ MCP-инструменты под ваши корп-системы
       Production-каналы, наблюдаемость, передача в эксплуатацию

4️⃣  PLATFORM CONSOLIDATION (опционально)
    └─ Если у вас уже есть свои AI-ассистенты — миграция на единое ядро

Что нужно от заказчика для старта

  1. Уточнить бизнес-функцию и желаемый сценарий (HR / юр / бух / саппорт / knowledge).
  2. Назначить владельца процесса со стороны заказчика.
  3. Подготовить набор корпоративных документов / шаблонов / FAQ для RAG.
  4. Согласовать контур развёртывания (SaaS / on-prem / гибрид).
