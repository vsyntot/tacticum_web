# Price Staff Order Workflow

Дата: 23.05.2026

## Product Model

`/price/` продаёт не только одиночного специалиста, а гибкую команду T&M. Базовые сценарии:

1. Быстрый заказ одного специалиста с выбранным уровнем и ставкой.
2. Сбор команды из нескольких ролей: пользователь добавляет карточки в состав заявки.
3. Изменение количества по каждой роли/уровню без повторного поиска карточки.
4. Гибкие параметры старта: дата может быть неизвестна, срок и загрузка могут обсуждаться.
5. Фиксированный дедлайн: один из пресетов срока раскрывает календарь точной даты окончания работ.
6. Быстрый поиск нужной роли через категорию, поиск, счётчик результатов и пустое состояние.
7. Передача заявки в текущий sale upstream без нового публичного endpoint.

## Implemented Scope

- Карточная кнопка добавляет специалиста в состав заявки, а не перетирает предыдущий выбор.
- Выбор уровня в карточке переведён с нативного `select` на segmented controls: уровень и цена меняются без раскрывающегося системного меню.
- Уровни в карточках выводятся в стабильном порядке `Junior -> Middle -> Senior -> Lead`.
- Фильтр и поиск показывают количество найденных специалистов, пустое состояние и быстрый сброс фильтров.
- AI-калькулятор `/price/` ограничен по высоте; новые сообщения прокручиваются внутри `[data-chat-messages]`.
- Модалка показывает список выбранных ролей, количество и суммарную часовую ставку.
- В составе заявки доступны `+`, `−`, удаление позиции, очистка состава и возврат к списку специалистов.
- Форма разделена на три зоны: состав заявки, контакты, параметры работы.
- Preset срока расширен: `срок обсуждается`, `короткий спринт до 2 недель`, `1 месяц`, `2–3 месяца`, `3–6 месяцев`, `дольше 6 месяцев`, `до конкретной даты`.
- При выборе `до конкретной даты` форма показывает обязательный календарь окончания работ и передаёт `endDate`.
- Вкладки фильтрации больше не получают нечитаемое серое hover/focus состояние: активная вкладка остаётся синей с белым текстом.
- Frontend отправляет `workers_json` и legacy summary-поля для обратной совместимости.
- `tacticum_sale_staff.php` принимает `workers_json` / `workers`, валидирует несколько позиций и формирует rich `workers[]` payload.
- Добавлена persistent mini-summary рядом со списком ставок: состав заявки, суммарная ставка, ориентировочный месячный бюджет и быстрые действия доступны без открытия модалки.
- Добавлены быстрые пресеты команды: `MVP`, `Discovery`, `Support`, `QA burst`; пресеты подбирают доступные роли из текущего контента инфоблока и не ломают сценарий, если часть ролей отсутствует.
- Добавлен расчёт ориентировочного месячного бюджета: `part-time = 80 ч/мес`, `full-time = 160 ч/мес`; при гибкой загрузке бюджет остаётся на уточнение.
- Backend принимает `team_preset` и `monthly_budget_estimate`, сохраняет их в rich staff payload и добавляет в текст заявки для текущего sale upstream.

## Acceptance Criteria

- `/price/` search скрывает неподходящие карточки и возвращает их после очистки.
- Empty search показывает пустое состояние и кнопку сброса.
- Category tab показывает только выбранную категорию; активная кнопка остаётся читаемой на hover/focus.
- Segmented-выбор Senior/Middle/Junior обновляет активное состояние, `aria-pressed`, ставку и payload заказа.
- При наличии нескольких уровней порядок не зависит от порядка элементов инфоблока и идёт от Junior к Lead.
- Light chat остаётся в пределах заданной высоты, а переполнение сообщений уходит во внутренний scroll.
- Клик по нескольким карточкам добавляет несколько строк в состав заявки.
- Изменение количества обновляет счётчик и суммарную ставку.
- Выбор срока `До конкретной даты` показывает календарь окончания работ; пустая дата блокирует отправку.
- Выбор пресета команды показывает persistent summary и заполняет `workers_json` без открытия модалки.
- При выборе `Part-time` или `Full-time` summary и модалка показывают ориентировочный месячный бюджет.
- Empty submit не создаёт лид и показывает client-side validation.
- Valid submit отправляет `workers_json`, `amount_of_workers`, `workload`, `duration`, `startDate`, `endDate`, `team_preset`, `monthly_budget_estimate`, контакты и описание задачи.
